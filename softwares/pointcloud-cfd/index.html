城市点云 CFD 几何建模平台 网页演示版

从 LiDAR 点云到可计算 CFD 城市几何：六个环节全程可在浏览器里演示 · 5 个真实城市场景 · 零第三方依赖

本平台把城市点云 CFD 几何建模的六个功能环节做成一个可在浏览器中直接演示的软件原型—— 多源数据融合建模 → 点云预处理 → 地形模型生成 → 建筑物几何提取 → 面向 CFD 的几何简化 → 几何清理与网格准备。 每个环节对应一个演示模块，页面上的每一个数值都来自当前数据集的实时计算或场景清单中的离线实测记录，不使用硬编码假数据。 平台为纯静态站点（HTML + CSS + 原生 ES Module），零第三方 JS/CSS 依赖、无构建步骤、零外部网络请求， 全部处理在浏览器内完成，点云与网格不上传任何服务器。

多源数据融合建模（P3）：DEM 晕渲 + 建筑轮廓 + 分类点投影四层独立开关；右侧面板给出三类数据源的本场景实际用量、 逐轮廓套合检查（有效轮廓 / 空轮廓 / 覆盖率 / 平均每栋点数）与数据源贡献度。

建筑物几何提取（二维视图）：建筑点云投影 + 原始足迹 + 最小二乘拟合矩形 + 凸包轮廓四层叠合， 读数浮层实时给出该栋点数、拟合点数与矩形边长；右侧下拉可按足迹面积选择单体，或开展拖拽框选批量拉伸。

建筑物几何提取（P4）：单体分割 + 最小二乘轮廓拟合（PCA 主轴 + 最小面积外接矩形 + 凸包）， 按 LoD1.2 平屋顶 / LoD1.3 双坡屋顶 / LoD2.2 面片屋顶拉伸成型；三维视图实时给出高度、底面面积、 三角面数与 openEdges，并可逐栋导出 OBJ。

几何清理与网格准备（P6）：破面与缝隙检测 → 按距离合并顶点修复 → 法向量检查与统一 → 体网格生成与质量验证， 四步流水线给出边界边、非流形边、欧拉示性数、翻转面数与体网格规模，用于说明模型封闭性与网格可用性。

主要功能

多源数据融合与套合检查 — LiDAR 点云 / GIS 矢量 / 航空摄影测量三类数据源对照本场景实际用量；逐轮廓统计缓冲区内建筑点数，输出有效轮廓数、空轮廓数、覆盖率与平均每栋点数，并与场景实测重建失败栋数对照。
点云预处理双路径 — 统计离群点滤波（SOR，k 近邻与 σ 倍数可调）给出原始 / 保留 / 剔除点数与剔除比例；CSF 布料模拟分类以「读取数据自带分类码」与「把类别视为未知几何重分类」双路径对照，输出一致率与混淆矩阵。重计算放在 Blob 内联 Web Worker 中，主线程不阻塞。
地形模型生成 — 以地面点为唯一输入栅格化 DEM（格内取中位数抗噪），配晕渲、等高线与高程剖面；给出格网、有效格数、空洞率与 min/max/mean/relief，并与数据集内置 DEM 逐项对照。
建筑物几何提取 — 单体分割与最小二乘轮廓拟合（PCA 主轴 + 最小面积外接矩形 + 凸包），LoD1.2 / 1.3 / 2.2 拉伸与几何有效性（openEdges、非流形边、欧拉示性数）；支持二维视图拖拽框选批量拉伸并合并导出 OBJ（单次最多 60 栋并如实提示）。
面向 CFD 的几何简化 — A 按最小面积阈值去除次要构件、B 按方向与尺寸归并为特征族、C 植被圆柱 / 球体 / 多孔介质三种简化模式；D 简化前后总账（栋数、独特几何体数、三角面、顶点、5 m 体素体网格量、建筑外表面积），并给出「同口径 LoD1.2 体块」与「实测重建网格」两条基线。
几何清理与网格准备 — 顶点焊接修复、边界边 / 非流形边 / 欧拉示性数统计、法向量检查与统一、体素体网格生成与质量验证（正交性、长宽比、面体比）；建筑层、地形层与全域三行分别统计，口径就地说明。
真实数据导入 — 一键多选导入 .ply .xyz .txt .csv .las .geojson .json .obj（单文件 ≤ 20 MB，LAS 点格式 0~5，点数上限 500 万自动抽样）；导入时按公共包围盒自动平移坐标以保护 WebGL 单精度精度，并如实记录平移量。
算法说明卡（面向客户讲解） — 每个模块页末尾附折叠的算法说明，逐条给出原理、公式、算法逻辑与接口；全平台共 33 个算法、133 条公式、34 张技术支持图（26 张手写 SVG + 8 张软件实测导出）。公式以 LaTeX 书写、由内置转换器转 MathML 原生排版，不引入任何第三方公式库。
二维 / 三维一键切换 — 数据视图均为「二维平面（俯视）」与「三维」双视图：三维基于 WebGL1 自研多图层视图，带重置视角 / 俯视 / 等轴测 / 侧视 / 自动旋转 / 截图 / 全屏 / 网格 / 背景 / 线框工具条，状态徽标实时显示 FPS、图层数、三角形数与相机距离。
零依赖、可审计、可离线 — 全站无第三方 JS/CSS、无打包器、无 sourcemap 偏差；评审方拿到的就是运行的那份代码。整目录拷到任意机器、用任意静态服务器即可运行，不受 CDN 与 npm 可用性影响。

获取与运行

  1. 软件部署在作者本机（本地静态站点，全部计算在浏览器内完成，数据不出本机）；本页面为软件介绍。
  2. 本机首次配置（一次性）：双击 城市点云CFD几何建模平台\注册软件协议.reg， 注册 pointcloud-cfd:// 启动协议。
  3. 日常使用：直接点击下方按钮——本机启动器会自动启动平台服务并打开界面 （服务已在运行时直接打开界面）；也可双击 城市点云CFD几何建模平台\启动软件.bat 手动启动。

技术依据与验证

平台技术依据为《城市CFD几何建模》汇报提纲与《城市点云 CFD 几何建模技术报告》，算法口径与报告同源； 交付文档包括主文档（功能、数据、导入、常见问题）、架构说明（分层、事件、数据集对象、二进制格式、生命周期与设计决策） 与验证记录（文件级 342 项数据校验、单元级 Node 断言、页面级无头浏览器 7 页验收、交互级 CDP 真实浏览器探针、视觉级像素分析）。 文档按源码的真实实现撰写，源码中的近似、抽样、上限保护与回退分支均写成明确局限——例如体素网格的正交性恒为 90°、 长宽比恒为 1.000 属理想化值，不能当作真实 CFD 网格质量指标；LoD2.2 在缺少屋顶面片数据时会回退到 LoD1.3。
